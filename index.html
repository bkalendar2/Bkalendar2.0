Cấu hình Đồng bộ Trực tiếp Google Calendar

Để đồng bộ trực tiếp 1-Click không cần qua file `.ics`, Google yêu cầu một mã OAuth Client ID cho ứng dụng cá nhân của bạn.

Mã này được lưu an toàn trong localStorage trên máy của bạn và không bị gửi đi bất kỳ đâu.

Chưa có Google Client ID? (Chỉ mất 2 phút tạo miễn phí):
  1. Vào Google Cloud Console → Tạo 1 Project mới.
  2. Vào APIs & Services > Library → Tìm và Bật Google Calendar API.
  3. Vào OAuth consent screen → Chọn External → Điền tên và thêm email của bạn vào Test Users.
  4. Vào Credentials > Create Credentials > OAuth client ID → Chọn Web application → Thêm Authorized JavaScript origins: http://localhost:3000.
  5. Sao chép Client ID dán vào ô trên và bấm Lưu!
